# Study Planner

A simple, responsive task manager for planning study sessions. Built with plain HTML, CSS and JavaScript (no libraries).

**Live demo:** https://your-username.github.io/study-planner

## Features

- Add tasks with a priority (High / Medium / Low) and an optional due date
- Mark tasks as done and delete them
- Filter by All, Pending or Done
- Progress bar showing how much is completed
- Overdue tasks highlighted
- Dark and light theme
- Tasks are saved in the browser using localStorage
- Works on mobile and desktop

## Tech Stack

- HTML5
- CSS3 (CSS variables, Flexbox, Grid, media queries)
- JavaScript (DOM manipulation, events, localStorage)

## How to Run

1. Download or clone this repository
2. Open `index.html` in your browser

## What I Learned

- Saving and loading data with localStorage
- Building a responsive layout and theme switching with CSS variables
